Compiled 2026-11-23 from Noah's project docs. Louis is building the defensive side; Noah owns the offensive side and the shell. ## What it is
One installable web app (iPad home screen) for high school football staffs. Plain HTML/JS, no AI inside it (built with AI help; data comes from imported sheets). Live at https://coachcorn.github.io/suite/. Repo: CoachCorn/coachcorn.github.io, branch main (suite/, almanac/, shared/, server/, mental-reps/). Positioning: "plan it once, everything else is already set up." Tagline: "From the whiteboard to the white lines." Name: KDNCE is taken (domain and an existing app); shortlist includes Grounds, Red Dirt, Fieldwork Football, Element, Field Manual (unchecked). Company working name: West Hall Labs.

## Tools in the suite (all share one glossary and one storage area)
- **Glossary**: one program vocabulary (formations, formation tags, motions, play tags, run/pass concepts, one words, fronts, coverages). Opens to category tiles with "needs a definition / not drawn yet" badges. Fill-in-the-blanks definition builders (formation tag, motion, formation, concepts, play tag, one word). Import words from a Hudl master playlist. New programs start blank (no preloaded glossary). Schema: claude/glossary-schema-v1.md.
- **Gameplan** (grid): coach-defined plan with one block per formation, drawing editor, personnel, predicted defense per formation, call grid. "Draw all looks" draws each call from the glossary rules. Formation and concept libraries. Sends to Almanac and Mental Reps.
- **Almanac**: sideline play logger (27-column Hudl export order, never change it). Predicted-call bar from the opponent scout. Manager mode for non-coach loggers (down, distance, spot, result only; coach adds calls later).
- **Film Room**: self-scout reports, 50/12, stats, film tagger, opponent scout pages, Hudl export, highlight clips in Cloudflare R2. AI auto-tagging is off (needs a server-side Claude API connection).
- **Stats** tab, **Mental Reps** tab (flashcard decks fed from the gameplan via an Apps Script endpoint).
- **Demo mode** when signed out: separate demo storage, fake season, nothing from Deer Creek.

## Infrastructure
- Cloudflare Worker "kdnce" with a D1 database and R2 bucket. One passcode per program. Documents sync with revision numbers (409 means merge). Secrets live only in the Cloudflare dashboard. Server code is in server/.
- Cloudflare deploys from GitHub on push. iPad apps must be fully closed and reopened to update.
- Workflow: bump the cache number in suite/sw.js or almanac/sw.js on every change. Test headless with Playwright against `python3 -m http.server 8123` from the repo root (run scripts with `python3 -I`). Push with `git -c push.negotiate=true push`. Everything is headless-tested in desktop Chromium only; nothing has run on a real iPad yet.
- Both sides edit the same repo. Suggested workflow (not formally agreed): work on a branch (`louis-defense` exists), open a pull request into main, Noah merges; check that offense still works before merging.

## What matters for the defensive side
- Predicted defense already exists on the offense side: the opponent scout (.xlsx/.csv, Hudl export "PlaylistData_<date>.xlsx", 27 columns) is read in shared/scout.js (a copy of the Almanac importer; keep them in step). Scout is split into opponent blocks (labeled by a row with only the PLAY # column filled, otherwise "Block N (plays a-b)"). Offense rows (ODK not D) are skipped.
- Lookup order, first level with at least 3 plays wins and the bar says which: formation + down/distance + field zone; formation + down/distance; formation only; down/distance only. Gameplan version: top two looks per formation, falls back to personnel, then all plays when n < 5.
- Real scout check: 347 defensive plays, 5 unlabeled blocks, 0 skipped. COVERAGE blank on 168 plays and FRONT FAMILY blank on 94, so percentages rest on tagged plays only. Coverage names are the opponent's own words (GREEN, CLAMP, BLACK, RUTH, JETER, SPOKE, CLEO).
- **Front technique codes (locked)**: odd fronts (strong - nose - weak): BASE 5-0-5, TITE 4-0-4, HEAVY 4i-0-4i, BEAR 3-0-3, MASS 2-0-2, OVER 4i-1-5, UNDER 5-1-4i, WIDE 9-0-9. Even fronts: INLAW 4-2i-2i-4, OUTLAW 5-3-3-5, VIPER 4-2-2-4, LOAD 9-3-1-5, CHOKE 4-0-4-9, BEAR 5-3-0-3-5, OVER 4-2-3-5, UNDER 5-3-2-4. BEAR/OVER/UNDER exist in both lists (the predictor shows the odd code with 3 rushers, otherwise only the name). MUG and BOSS are suffix modifiers (for example "505 BOSS"). TUFF, PLUS and push/pull are dropped. Correction (Noah and Louis, 11/23): OVER/UNDER are fixed to the defense's left and right, a defensive rule everywhere including scout data, not relative to TE strength. Under = front slides to defense-left (5-1-4i written left to right); Over is the mirror (4i-1-5). Louis's page had Over as the offense's right, which is reversed. See claude/defense-vocabulary-decisions-2026-11-23.md for the full list of defensive decisions (positions, techniques, pressures, packages, strength setting).
- Glossary seeds fronts with codes, 7 coarse shells and 6 named coverages. Black, Clamp, Cleo, Sink and Read are flagged for review until mapped to shells.
- Noah would not tag fronts live; the model relies on past data. He wants to be able to rename or add a front/technique himself (not built; the TECH table is hardcoded). Open decision: retag raw scout data with codes vs keep names and translate in a lookup layer (currently the lookup layer).
- Best call: the Almanac bar has a "Best call" column (G().best = { "FRONT|RUSH|COVERAGE": "CALL", "COVERAGE": "CALL" }); the gameplan "favorite call into ____" grid that would fill it is not built.
- Midweek suggestion notes (planned): each concept's EFF and explosive rate as a percentage-point difference vs the opponent's own average, shown as separate green/red numbers with clip count, 3-clip floor, no ranking.
- Rules: EFF = 1st down 4+, 2nd down half the distance rounded up, 3rd/4th convert. Explosive = 15+ on any play (the Almanac's own stats still use 12 run / 16 pass; ask Noah before changing).
- UI plan: Offense/Defense side switch on the home screen next to the sync status. Hide defense tabs in demo and booth builds until Louis's side is ready. Defensive look library (save a defensive look to reuse) is an idea only. Gameplan drawing defaults for defenses (4-3-4, 3-4-4, 3-3-5, 4-2-5) exist as templates; defensive templates were spread out on 11/22.
